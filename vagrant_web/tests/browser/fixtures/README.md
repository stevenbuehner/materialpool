# Browser-Test-Fonts

`raleway-latin.woff2.base64` ist die Latin-Teilmenge von Raleway, welche die
Anwendung über Google Fonts lädt. Die Base64-Kodierung erlaubt es, die binäre
Testfixture reproduzierbar über die üblichen Textwerkzeuge zu pflegen.

- Quelle: `https://fonts.gstatic.com/s/raleway/v37/1Ptug8zYS_SKggPNyC0IT4ttDfA.woff2`
- Abgerufen: 12. September 2026
- SHA-256 nach Base64-Dekodierung:
  `10f1a0ef3f3497901c1c3e9987d0cb97d092a6ce1ff45669a1aed503cf67e6ef`
- Lizenz: `raleway-OFL.txt`

Der Browser-Helfer stellt die Datei ausschließlich innerhalb der
Playwright-Kontexte bereit. Produktionsassets und Typografie werden dadurch
nicht verändert.
